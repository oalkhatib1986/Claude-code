Session type

Blocks

Build each block below: + Add exercise gives one exercise with its own time; + Group exercises puts several exercises on one shared time. The red dot marks an exercise or group as scored. Blocks run their items top to bottom when the trainer starts them. Added things separately? Use ⤴ on any item to group it with the one above, and ⤵ on a grouped exercise to ungroup it.
How a session runs: teams walk to a station and pick their team on that erg's screen. The trainer starts each block from this board when everyone is set. Each block runs its exercises and groups top to bottom on their own times; anything marked with the red dot is scored and banks to the leaderboard. Each station is a bank of machines (e.g. your 5 rowers) — in scored work the whole team's ergs count at once.

Waves

Athletes are grouped into waves by their order in the Teams list (first N = wave 1, next N = wave 2 …). Every wave races the same stations below, and each athlete's clock starts when their wave is released — so the leaderboard (fastest total time) is fair across waves.

Teams

Teams are assigned automatically in order: Teams 1, 2, 3 fill Block 1’s machines 1, 2, 3; the next teams take Block 2, and so on. Every round each group moves together to the next block; the screens tell every team where to go. Nobody picks anything.
