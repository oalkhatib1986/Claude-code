How a session runs: everyone is assigned to a machine automatically — every screen shows who goes where. The trainer starts each block when the floor is set. Each block runs its exercises and groups top to bottom on their own times; anything marked with the red dot is scored and banks to the leaderboard.

Waves

Athletes are grouped into waves by their order in the list (first N = wave 1, next N = wave 2 …). Every wave races the same stations below, and each athlete's clock starts when their wave is released — so the leaderboard (fastest total time) is fair across waves.
